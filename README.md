# SafeStay

SafeStay is a responsive short-term housing application that helps students, interns, international students, and young professionals find safe, furnished, and trustworthy housing.

The application presents important information such as monthly rent, lease length, furnishings, utilities, pet policies, property details, and neighborhood safety scores. Users can filter available properties, review individual listings, and save housing options for later comparison.

## Project Purpose

Finding reliable short-term housing can be difficult, especially for people temporarily relocating for school, internships, or work. Pricing, safety, utilities, lease requirements, and furnishing information may be unclear or distributed across multiple sources.

SafeStay is designed to make this process more transparent by presenting important housing information in a consistent and easy-to-scan format. Its goal is to help users compare options efficiently and feel more confident about their housing decisions.

## Features

- Responsive desktop, tablet, and mobile layouts
- Searchable housing listings
- Filters for:
  - Minimum and maximum budget
  - Property type
  - Lease length
  - Bedrooms and bathrooms
  - Furnished status
  - Pet policy
  - Move-in date
- Sorting by price and neighborhood safety
- Individual property details
- Neighborhood safety scores
- Furnishing, utility, and lease information
- Save and remove favorite listings
- Browser storage with `localStorage`
- Contact-landlord form
- Empty, loading, and no-results states
- Responsive mobile navigation

## Application Pages

- `index.html` — Homepage and introduction
- `listings.html` — Property search, filters, and sorting
- `details.html` — Individual property information
- `favorites.html` — Saved housing listings
